## 💻 How to Run the Code

1. Install Python on your computer.
2. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

3. Navigate to the project directory:

   ```bash
   cd python-practice
   ```

4. Run a Python file:

   ```bash
   python 1.main_practice.py
   ```

You can also open the project in Visual Studio Code and run the files using its Python extension.
